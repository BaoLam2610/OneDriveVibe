# Font

Be Vietnam Pro (400, 500, 600, 700, 800) và JetBrains Mono (400, 500), giấy phép SIL Open Font License 1.1.

- Be Vietnam Pro: https://github.com/google/fonts/tree/main/ofl/bevietnampro
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono

File nằm ở `src/androidMain/res/font/`, tên theo quy tắc snake_case của Android.
